# SHAPE

Dieta e treino sob medida. Criado por Ted Borges Dias Luz.

App de uma página que calcula calorias e macros (Mifflin-St Jeor), monta um cardápio com porções que batem os macros e gera o treino da semana. Tem sequência de dias com calendário, horários das refeições, dias de treino e metas personalizáveis. Tudo fica salvo no navegador.

Funciona no celular como app instalável: no Android, toque em "Instalar app"; no iPhone, use Compartilhar > Adicionar à Tela de Início. Depois de aberto uma vez, funciona sem internet.

Para rodar localmente, sirva a pasta com qualquer servidor estático (por exemplo `python3 -m http.server`) e abra no navegador. Não há build nem dependências.
