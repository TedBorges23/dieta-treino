# Forma

Dieta e treino sob medida. App de uma página que calcula calorias e macros (Mifflin-St Jeor), monta um cardápio com porções que batem os macros e gera o treino da semana. Horários das refeições, dias de treino e metas podem ser personalizados, e tudo fica salvo no navegador.

Para rodar localmente, abra `index.html` no navegador. Não há build nem dependências.

Ícones: [Lucide](https://lucide.dev) (licença ISC), embutidos no arquivo.
